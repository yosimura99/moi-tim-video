Cài đặt khóa Google

Google Search là nguồn chính cho cả từ khóa và địa chỉ trang web. YouTube Data API bổ sung video YouTube, thời lượng và giờ đăng. Khóa chỉ nằm trong trình duyệt này.

Lấy khóa và mã cx

  1. Mở Google Cloud Console và tạo một dự án, hoặc chọn dự án có sẵn.
  2. Vào APIs & Services → Library. Bật Custom Search API và YouTube Data API v3. Đợi vài phút cho API có hiệu lực.
  3. Vào APIs & Services → Credentials → Create credentials → API key. Sao chép khóa.
  4. Nên hạn chế khóa: Application restrictions → HTTP referrers. Thêm http://localhost/*, http://127.0.0.1/* và địa chỉ Pages, ví dụ https://ten-ban.github.io/*. Ở API restrictions, chỉ chọn Custom Search API và YouTube Data API v3.
  5. Mở Programmable Search Engine. Khi được hỏi tìm ở đâu, chọn Search the entire web. Tạo xong, sao chép Search engine ID — đó là mã cx.
  6. Dán khóa và cx vào form, bấm Kiểm tra khóa. Khi Google và YouTube đều báo dùng được, bấm Lưu.

Mỗi lượt tìm có thể tốn 1–2 truy vấn Custom Search (mức miễn phí khoảng 100 lần/ngày) và một lần tìm YouTube (100 đơn vị; hạn mức mặc định khoảng 10.000 đơn vị/ngày). Tự làm mới cũng tốn hạn mức. Khóa không được đưa vào Git. Ai mở trang này đều phải tự dán khóa của họ.

Chưa có khóa? Một liên kết video YouTube (watch, youtu.be, shorts) vẫn hiện được tên và ảnh. Kênh, playlist và từ khóa cần khóa — YouTube không cho trang tĩnh đọc RSS.
